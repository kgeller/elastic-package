To set up the Bitwarden integration, follow these steps:

1. Log in to your Bitwarden account and navigate to the 'Settings' section.
2. Under 'Account Settings', select 'API Keys'.
3. Click 'Create API Key' and provide a name for the key (e.g., 'Elastic Integration').
4. Copy the generated API key as you will need it later.
5. In the Bitwarden web interface, navigate to the 'Organization' section and select your organization.
6. Under 'Organization Settings', select 'API Keys'.
7. Click 'Create API Key' and provide a name for the key (e.g., 'Elastic Integration').
8. Copy the generated API key as you will need it later.
9. Refer to the Bitwarden API documentation (https://bitwarden.com/help/api/) for more information on available API endpoints and how to authenticate with the API keys.

Note: The API keys generated in steps 4 and 8 are required to authenticate with the Bitwarden API and retrieve event data. Keep these keys secure and do not share them with unauthorized parties.
